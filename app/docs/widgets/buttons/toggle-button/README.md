# Toggle Button

A toggle switch that sends one command when switched ON and another when switched OFF.

## Parameters

| Parameter    | Type   | Default | Description                                          |
|--------------|--------|---------|--------------------------------------------------------|
| Title        | text   | —       | Optional label shown above the switch.                 |
| ON Command   | text   | —       | Command sent when the switch is turned on.             |
| OFF Command  | text   | —       | Command sent when the switch is turned off.             |
| Datasource   | option | —       | Serial or Fast Frame datasource that receives the command. |
