# Pointer

| Widget View | Edit Widget Window View |
|---|---|
| ![Widget screenshot](widget.png) | ![Edit dialog](widget-edit.png) |

Animated directional pointer driven by a calculated angle expression.

## Parameters

| Parameter | Type       | Default | Description                                  |
|-----------|------------|---------|----------------------------------------------|
| Direction | calculated | —       | Angle in degrees (0 = up, 90 = right).       |
| Caption   | text       | —       | Label rendered in the centre of the pointer. |
| Units     | text       | —       | Unit suffix appended after the caption.      |
