# Google Map

![Widget screenshot](widget.png)

Embedded Google Map centred on a calculated latitude/longitude position.

## Parameters

| Parameter | Type       | Default | Description                                     |
|-----------|------------|---------|-------------------------------------------------|
| Latitude  | calculated | —       | Latitude of the map centre in decimal degrees.  |
| Longitude | calculated | —       | Longitude of the map centre in decimal degrees. |
