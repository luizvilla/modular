# Fast Frame Plot

![Widget screenshot](widget.png)

Plots one or more fast-frame CSV channels against a selected X column or sample index.

## Parameters

| Parameter | Type | Default         | Description                     |
|-----------|------|-----------------|---------------------------------|
| Title     | text | Fast Frame Plot | Label shown in the pane header. |

## Notes

Axes, bounds, CSV source, X column, and channel definitions are configured through the **Fast Frame UI** and **Fast Frame Channel Manager** helper widgets. Add them to the same pane to expose the full configuration panel.
